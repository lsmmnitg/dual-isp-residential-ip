## 双ISP住宅IP vs 原生IP vs 数据中心IP

这三个概念经常被混淆，但它们决定了你的IP能不能通过平台风控。

**数据中心IP**：IP归属显示为"Hosting"或"Datacenter"，风控系统会直接标记为服务器。大多数便宜VPS都是这类IP。优点是便宜，缺点是平台风控严、解锁能力差。做跨境业务基本没法用。

**原生IP**：IP的WHOIS记录和地理位置都属于目标国家/地区，但不一定是住宅IP。比如Netflix能识别出这是美国IP，但平台风控可能还是会判定为数据中心。

**双ISP住宅IP**：既是原生IP，又挂真实宽带运营商名称，在风控系统里显示为普通家庭宽带用户。这是三种IP里纯净度最高、风控通过率最高的。

平台风控检测IP时，会查询IP所属的网络类型和历史记录。你可以通过ipinfo.org查看"org"字段，如果显示的是"Comcast"、"Verizon"、"GTT"这类真实运营商名称，或者直接标注"residential"（住宅），风控系统就会把它当成正常家庭用户；如果显示"hosting"、"datacenter"、"VPN"、"proxy"，就会被归为高风险。

Scamalytics.com可以查欺诈风险评分，0分是理想状态，表示这个IP段从未被大规模滥用。双ISP住宅IP因为来自真实宽带运营商，且通常是新分配或定期更换的IP段，欺诈值普遍很低。

如果你只是搭个梯子看Netflix，原生IP够用；如果你要做跨境电商、养TikTok账号、或者运营多个社交媒体账号，双ISP住宅IP是标配。
